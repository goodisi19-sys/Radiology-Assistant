# Рентгенолог — экспертный помощник

Для Windows x64 с 16 ГБ ОЗУ и без видеокарты используется переносимый
llama.cpp CPU и локальная модель Qwen2.5-3B-Instruct Q4_K_M (~2,1 ГБ).
Права администратора, установка службы, Python и Ollama не требуются.
Работа может быть запрещена политикой организации для любых сторонних EXE:
переносимый формат не обходит такие ограничения.

1. Распакуйте весь архив RadiologyAssistant-Windows: папка `local-ai` должна
   остаться рядом с RadiologyAssistant.exe. Движок определяется автоматически.
2. Один раз скачайте модель из официального репозитория Qwen:
   https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q4_k_m.gguf
   Сохраните её в удобной папке. Модель не включена в архив приложения.
3. Выделите описание и нажмите «Рентгенолог — экспертный помощник»
   (Ctrl+Alt+E), затем выберите GGUF. Пути запоминаются в вашей SQLite.
   Если ничего не выделено, используется весь документ.
4. В поле «Что сделать с текстом?» укажите задачу: например, «перепиши весь
   протокол профессиональным языком, структурируй описание и заключение».
   Флажок «Обработать весь протокол» позволяет расширить выделение до документа.
   Ваш запрос запоминается. «Новый вариант» запускает локальный движок на четырёх потоках CPU.
   Первый запуск загружает модель; ответ может занять несколько минут.
   Повторное нажатие использует новое случайное зерно. Вариант может повториться.
5. Сравните исходник и предложение. «Применить вариант» заменяет только
   выбранный фрагмент; Ctrl+Z отменяет замену. Если документ был изменён во время
   просмотра, откройте помощник заново. Исходник не заменяется автоматически.

Обработка идёт в фоновом потоке. Движок доступен только через 127.0.0.1,
запускается в offline-режиме без веб-интерфейса и завершается после ответа.
Текст не отправляется в облако. Для генерации интернет не нужен.
Не закрывайте приложение во время обработки; предусмотрены таймауты загрузки
и ответа. На ПК со старым CPU может потребоваться другая сборка llama.cpp.

Модель предназначена для редактирования языка и не анализирует изображения.
Она не может определить правильные сигнальные характеристики из неполного
описания. В запросе запрещено менять факты, отрицания, сторону, размеры,
последовательности и сигнальные характеристики. Различия в числах, единицах, стороне, обозначениях последовательностей и
словах гипо-/изо-/гиперинтенсивности выводятся как предупреждения. Например,
повтор размера в заключении также может вызвать предупреждение. После
сравнения с исходником отметьте «Я проверил отмеченные различия…», чтобы
применить вариант. Жёсткого запрета на такую редактуру нет. Это не гарантирует медицинскую эквивалентность: итог проверяет врач.
На слабом CPU допустима Qwen2.5-1.5B-Instruct GGUF, но качество ниже.

llama.cpp: https://github.com/ggml-org/llama.cpp/releases/tag/b12322
Лицензия MIT включена в `local-ai/LICENSE-llama.cpp.txt`.
Модель Qwen2.5-3B распространяется отдельно: перед загрузкой ознакомьтесь с
лицензией и карточкой в её репозитории Hugging Face.

# Быстрые строки протоколов

Вкладка «Фразы» заменена на «Быстрые строки протоколов». Выделите текст в
редакторе → правая кнопка мыши → «Добавить в быстрые строки протоколов».
Либо нажмите Ctrl+Alt+L. Строка сохраняется точно как выделена (кроме внешних
пробелов), без изменения медицинских формулировок. Точные повторы не добавляются.
Список хранится в SQLite, переживает обновления, включается в резервные копии
и доступен также в отдельном окне по Ctrl+Shift+L. Старая библиотека фраз и
приоритет личных стандартов остаются доступны автодополнению.

Полный протокол: до 16 000 символов, запрос до 2 000 символов. Контекст
увеличен до 16 384 токенов, ответ — до 4 096 токенов. Длинный ответ на CPU
может занять несколько минут (таймаут ответа 10 минут). Обрезанный ответ
не подставляется в документ. Можно менять структуру, стиль и терминологию
целиком, сохраняя исходные клинические факты.
